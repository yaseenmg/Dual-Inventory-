# Source completeness status

The Java sources, Gradle build files, resources, and Gradle launcher scripts are tracked in this repository.

**Known limitation:** `gradle/wrapper/gradle-wrapper.jar` is not currently committed. Therefore `gradlew` and `gradlew.bat` will report that the wrapper JAR is missing until that binary is added. The original source archive contains this JAR; the repository upload path used for the text files did not transfer binary files directly.

The project has not yet been successfully compiled or tested from this GitHub checkout. Do not treat the current repository state as a verified build.
